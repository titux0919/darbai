# JavaFX Hotels App

Galutinis clean variantas be legacy `MainApp.java` / `Launcher.java` failų.

## Paleidimas

```bash
./mvnw clean compile
./mvnw javafx:run
```

Windows:

```bat
mvnw.cmd clean compile
mvnw.cmd javafx:run
```

## Entry point

Vienintelis pagrindinis paleidimo taškas:

```text
src/main/java/lt/praktika/hotelapp/Main.java
```

JavaFX aplikacijos klasė:

```text
src/main/java/lt/praktika/hotelapp/app/HotelApplication.java
```
